02 / The methodology

Read the notes

Real sites, not synthetic tests.

Dozens of websites, from the BBC to MDN and the ECMAScript specification. One general configuration per minifier, applied to the same source pages.

Warmed up, measured as fairly as possible.

Five timed runs per site after warm-up, using the median. Local minifiers run in their own processes and take turns in rotating order; times cover the minification call only.

Transparent about the trade-offs.

Failed sites count as unminified in size averages. Maximum minification is not a like-for-like comparison. Correctness caveats are documented.
